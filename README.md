# Culminating Point: Feedback & Issue Tracker

This repository is the **public issue tracker** for [Culminating Point](https://culminating-point.com), a real-time logistics wargame of the war in 1941.

There is no code here. File a bug, request a feature, report a balance or history problem. The maintainer triages weekly. English or Italian, whichever you prefer.

## Before filing

- **A question, not a bug?** Ask in [Discussions](../../discussions) or email [hello@culminating-point.com](mailto:hello@culminating-point.com).
- **A privacy concern?** Use [privacy@culminating-point.com](mailto:privacy@culminating-point.com).
- **Already filed?** Check the [open issues](../../issues). A thumbs-up counts more than a duplicate.

## Filing

Use the [issue templates](../../issues/new/choose):

- **Bug**: something broke, looks wrong or behaves oddly
- **Feature**: something missing, or that should work differently
- **Balance or history**: a unit, a map, a supply rule or an outcome that does not fit the war it models

The game writes its state in the address bar. Pasting that link into a bug report lets the maintainer reopen what you saw.
